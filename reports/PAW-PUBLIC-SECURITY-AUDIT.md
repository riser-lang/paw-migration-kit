# PAW 公开仓库安全审计

仓库保持公开。审计不修改仓库可见性，不删除 Actions 运行或产物。

当前 API 元数据快照：21 次 Actions 运行、20 个未过期产物，总计 5,649,455,197 字节。未删除运行或产物。只读扫描了 21 份 Actions 日志：未命中私钥块、GitHub/Tailscale/COS token、Windows 个人路径或已配置云主机地址；发现 23 个不同的公网 IPv4（合计 392 次命中），未见私网、回环或链路本地地址。日志出现 12 次邮箱样式字符串，来源尚未可靠归类到具体软件发布者。此前已检查的最新成功 ISO 产物未发现用户云主机凭据；所有历史产物二进制内容未在本轮重新下载复扫。

本地公开安全扫描覆盖当前文件；新增 CI 脚本遍历可达 Git blob，匹配私钥块、IPv4、邮箱、个人路径、GitHub/Tailscale/COS 凭据等标记，并只输出类别、路径和行号，不输出命中值。工作区可达的 186 个 Git 对象扫描通过；CI 会在全历史 checkout 上复扫。GPT 分区类型 GUID 属于格式标准值，扫描器仅对这两个标准值放行。Actions 产物元数据已核对；完整历史产物内容未重新下载扫描，以免重复下载数 GB 产物。

不得把账户、密钥、真实服务器 IP、云资源标识或本机个人路径写入仓库。GitHub runner 的全历史扫描尚未执行；新分支本地提交邮箱使用 GitHub no-reply 地址。日志扫描命中数量不等同于敏感信息泄漏，邮箱样式字符串仍需之后按发行商来源归类。
